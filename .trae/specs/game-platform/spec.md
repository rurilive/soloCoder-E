# 小游戏平台 - Product Requirement Document

## Overview
- **Summary**: 开发一个插件化的小游戏平台，支持多种小游戏以插件形式集成。首先实现打地鼠游戏作为样例，包含多用户排名系统、实时对战功能、用户评价系统和开发者回复功能。
- **Purpose**: 构建一个可扩展的小游戏平台，让用户可以方便地访问和游玩各种小游戏，同时支持开发者发布游戏、查看评价和回复用户。
- **Target Users**: 游戏玩家、小游戏开发者

## Goals
- 构建一个插件化的游戏平台架构，支持动态加载和管理不同的小游戏
- 实现打地鼠游戏作为首个样例插件
- 提供多用户排名系统，支持分数统计和排名展示
- 实现实时对战功能，支持多名玩家同时在线对战
- 开发评价系统，支持用户对游戏进行评分和评论，开发者可以回复评论
- 使用 FastAPI、uv、Jinja2 技术栈实现后端和前端渲染

## Non-Goals (Out of Scope)
- 不实现用户注册/登录的完整认证系统（可以使用简单的用户名模拟）
- 不实现支付系统或游戏内购买功能
- 不实现游戏开发者管理后台（除了评价回复功能）
- 不实现复杂的权限管理
- 不实现移动端原生应用（仅Web端）

## Background & Context
- 当前目录为空，需要从零开始构建项目
- 技术栈已指定：Python + FastAPI + uv + Jinja2
- 需要插件化架构，以便后续可以轻松添加更多游戏

## Functional Requirements
- **FR-1**: 插件化游戏架构
  - 支持游戏以插件形式注册到平台
  - 提供统一的游戏接口规范
  - 支持游戏的动态加载和管理
- **FR-2**: 打地鼠游戏
  - 实现经典的打地鼠游戏玩法
  - 支持不同难度级别
  - 记录玩家得分
- **FR-3**: 多用户排名系统
  - 记录玩家游戏得分
  - 按游戏维度展示排名
  - 支持历史最高分和最近得分
- **FR-4**: 实时对战功能
  - 支持两名玩家实时对战
  - 实时同步游戏状态
  - 展示对战结果
- **FR-5**: 评价系统
  - 用户可以对游戏进行评分（1-5星）
  - 用户可以撰写文字评论
  - 开发者可以回复用户评论
  - 展示评价列表和平均评分

## Non-Functional Requirements
- **NFR-1**: 性能
  - 页面加载时间 < 2秒
  - WebSocket实时消息延迟 < 100ms
- **NFR-2**: 可扩展性
  - 插件架构允许无需修改核心代码即可添加新游戏
  - 数据库设计支持水平扩展
- **NFR-3**: 可用性
  - 界面简洁直观，易于使用
  - 错误提示友好
- **NFR-4**: 安全性
  - 防止SQL注入（使用ORM）
  - 防止XSS攻击（模板自动转义）
  - WebSocket连接验证

## Constraints
- **Technical**:
  - 必须使用 Python 作为后端语言
  - 必须使用 FastAPI 作为Web框架
  - 必须使用 uv 作为包管理工具
  - 必须使用 Jinja2 作为模板引擎
  - 可以使用 SQLite 作为数据库（便于开发）
- **Business**:
  - 项目需要在合理时间内完成
  - 代码需要可维护和可扩展
- **Dependencies**:
  - FastAPI
  - uvicorn (通过uv)
  - Jinja2
  - SQLAlchemy (数据库ORM)
  - python-multipart (表单处理)
  - websockets (实时通讯)

## Assumptions
- 用户可以通过简单的用户名标识（无需密码认证）
- 实时对战使用 WebSocket 实现
- 打地鼠游戏使用前端JavaScript实现，后端记录得分
- 评价系统支持增删改查

## Acceptance Criteria

### AC-1: 插件化架构
- **Given**: 平台已启动
- **When**: 注册一个新游戏插件
- **Then**: 游戏列表中显示新游戏，用户可以访问和游玩
- **Verification**: `programmatic`
- **Notes**: 验证游戏注册和访问流程

### AC-2: 打地鼠游戏功能
- **Given**: 用户进入打地鼠游戏页面
- **When**: 用户开始游戏并击打地鼠
- **Then**: 游戏正常运行，计分准确，游戏结束后显示得分
- **Verification**: `programmatic` + `human-judgment`
- **Notes**: 验证游戏逻辑、计分系统和UI展示

### AC-3: 排名系统
- **Given**: 多个玩家完成了游戏
- **When**: 查看排名页面
- **Then**: 按分数从高到低显示玩家排名，包含用户名、分数、时间
- **Verification**: `programmatic`
- **Notes**: 验证排名排序和数据展示

### AC-4: 实时对战
- **Given**: 两名玩家进入对战房间
- **When**: 对战开始，双方进行游戏
- **Then**: 双方实时看到对方的游戏状态和得分，对战结束显示结果
- **Verification**: `programmatic` + `human-judgment`
- **Notes**: 验证WebSocket连接、实时同步和对战结果

### AC-5: 评价系统 - 用户评分
- **Given**: 用户已游玩某游戏
- **When**: 用户提交评分（1-5星）和评论
- **Then**: 评价成功保存，显示在游戏评价列表中，平均评分更新
- **Verification**: `programmatic`
- **Notes**: 验证评价创建、存储和展示

### AC-6: 评价系统 - 开发者回复
- **Given**: 有用户评价存在
- **When**: 开发者回复该评价
- **Then**: 回复成功保存并显示在原评价下方
- **Verification**: `programmatic`
- **Notes**: 验证开发者回复功能
