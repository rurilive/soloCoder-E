```
│       ├── app.js             # 主应用入口
│       ├── utils.js           # 工具函数

│       ├── canvas.js          # 画布控制 (缩放、平移)
│       ├── nodes.js           # 节点管理 (拖拽、选中)

│       └── properties.js      # 属性面板

├── pyproject.toml             # UV 项目配置
├── .gitignore                 # Git 忽略文件
└── README.md
```

## 已实现的功能

### 后端功能
- **API 接口**: 工作流 CRUD、运行、导出
- **执行引擎**: DAG 拓扑排序 (Kahn算法)、数据流管理
- **安全沙箱**: RestrictedPython 限制危险操作 (禁止 `import os`、文件读写等)
- **代码导出**: 将工作流导出为独立 Python 脚本

### 前端功能
- **三栏布局**: 左侧节点库、中间画布、右侧属性面板
- **画布操作**: 滚轮缩放、拖拽平移、无限画布
- **节点系统**: 拖拽创建、移动、选中、删除
- **连线系统**: 从输出点拖拽到输入点创建连接
- **属性面板**: 根据节点类型显示不同的编辑界面
- **输出面板**: 显示日志、结果、错误信息

## 使用说明

1. **打开浏览器**访问 `http://127.0.0.1:2222/`
2. **创建工作流**:
   - 从左侧节点库拖拽节点到画布 (Start、End、Python Code、Condition)
   - 从节点的输出点 (右侧蓝点) 拖拽到另一个节点的输入点 (左侧蓝点) 创建连接
3. **配置节点**:
   - 点击节点选中，右侧属性面板显示配置项
   - Start 节点: 设置初始参数 (Key-Value 形式)
   - Python Code 节点: 编写 Python 代码
   - Condition 节点: 设置条件表达式
4. **保存/运行**:
   - 点击顶部 **保存** 按钮保存工作流
   - 点击 **运行** 按钮执行，底部输出面板显示结果
5. **导出**:
   - 点击 **导出** 按钮下载 Python 脚本

## 示例工作流

创建一个简单的工作流:
1. **Start** 节点: 设置参数 `name: "World"`, `multiplier: 3`
2. **Python Code** 节点: 编写代码:
   ```python
   greeting = f"Hello {name}"
   tripled = 10 * multiplier
   result = {"greeting": greeting, "tripled": tripled}
   ```
3. **End** 节点: 接收结果
4. 连接: Start → Python Code → End
5. 保存 → 运行
